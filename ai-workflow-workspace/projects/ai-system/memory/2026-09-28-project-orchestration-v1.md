# Project Orchestration V1

- AI System is the owner's coordination interface for managed projects; each target's installed AI Workflow is authoritative for risk, phases, QA, technical status, and technical distillation.
- Resolve workspace, nearest owner, real repository, target `AGENTS.md`, local Workflow version, and Workflow project ID before routing work. Similar names do not establish identity.
- An orchestration record keeps owner intent, approved scope, write owner, baseline, and evidence links. It does not create approval or duplicate technical memory.
- Read-only preflight returns `inspect-local-gates`, which requires local semantic review before writes. Stop on ambiguous project, incomplete installation, instruction conflict, or unknown concurrent writer.
- A target-project push, production action, or final owner check needs target-scoped owner authority; publication of the AI System upgrade does not supply it.
