# System Insight Entries

Store detailed anonymized System Insight entries here.

Create one file per entry:

```text
YYYY-MM-DD-short-kebab-title.md
```

Use `.systems/ai/templates/system-insights/system-insight.template.md`.

Every entry must include:

- required distillation sections from `TEMAT` through `8. WALIDACJA OPERACYJNA`;
- privacy check;
- source scope;
- skill candidate field;
- suggested skill target.

Do not store raw client data, client names, secrets, repo-specific facts, project-specific details, or production identifiers.
