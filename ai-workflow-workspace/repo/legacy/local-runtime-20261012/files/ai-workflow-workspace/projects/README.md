# Projects

## Purpose

Full project workspaces live here.

Create projects through `phase-0-project-workspace` or `.systems/scripts/init-workspace` followed by repo/project intake.

Project paths:

```text
AI_WORKFLOW_WORKSPACE_HOME/projects/<project>/
```

Do not copy `.systems/ai/examples/projects/EXAMPLE` as active facts. Use templates and create project-specific runtime artifacts.
