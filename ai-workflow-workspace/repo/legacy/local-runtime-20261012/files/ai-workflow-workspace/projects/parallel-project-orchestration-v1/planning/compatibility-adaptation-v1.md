## Architecture
AI System owns intent and its canonical state; installed local Workflow owns project execution and phases.
A closed compatibility envelope maps the two different schema-1 shapes, never aliases them.
The original reducer remains an inspection API; new strict helpers supplement it and cannot spawn, copy, merge, approve, commit or push.
Separate modules own compatibility/recovery, canonical capture and source-commit binding. One coordinator writes shared state.
Actual inventories and Git proof are recomputed; declarative booleans never attest a native backend.
Persisted metadata uses exclusive local locks, expected revisions and atomic replacement. Unknown effects retain reservations.
Historical sources and records are not rewritten.
