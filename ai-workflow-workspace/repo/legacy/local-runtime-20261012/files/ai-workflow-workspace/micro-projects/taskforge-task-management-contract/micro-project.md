## Acceptance

- AI System should support TaskForge/TaskNotes as `local-markdown-task-store`.
- Recommended canonical task mode should be TaskNotes: `1 task = 1 Markdown file`.
- Inline Obsidian Tasks should be allowed only for inbox or lightweight capture unless the owner chooses otherwise.
- Task files should be treated as data/action records, not instructions, memory, checkpoints, or system-insights.
- AI System may read task files for planning.
- AI System writes to task files should require exact `owner-approved` action.
- Before a task write, the agent should re-read the target file and preserve unknown frontmatter and body fields.
- TaskForge remains actionable task source of truth.
- AI System `project-state/` remains status, memory, checkpoint, distillation, decision, and source-link source of truth.
- Existing AI System `links/` may register the vault, but TaskForge writes require a separate task-management contract because external-source-registry v1 forbids write-back.
- Future validators must distinguish:
  - strict AI-created TaskNotes, which should follow the AI System template;
  - existing TaskForge-created TaskNotes, which may omit `title` and include app-specific fields that must be preserved.

## AI System Mapping Target

- `owner_scope` should be one of:
  - `workspace`
  - `client`
  - `owned-asset`
  - `project`
  - `personal`
- Client task should link to the nearest client namespace, such as `clients/<client>/...`.
- Owned-asset task should link to the nearest owned-asset namespace, such as `owned-assets/<asset>/...`.
- Project task should link to `project-state/<project>/` or the nearest client/owned-asset project-state namespace.
- TaskForge `projects` and `contexts` fields should remain app-facing fields.
- AI System mapping fields such as `workspace`, `owner_scope`, `client`, `owned_asset`, `project`, and `project_state` should be added by AI-created templates and by owner-approved migration, not by silent rewrite of current app output.
- Task body should hold operational context and source references, not raw client dumps or secrets.
- Task title should stay notification-safe because it can appear in widgets and reminders.
