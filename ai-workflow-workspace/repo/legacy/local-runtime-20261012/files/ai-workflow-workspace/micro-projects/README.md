# Micro-projects

## Purpose

Micro-projects are small low-risk repo-level work items that do not need a full project workspace.

Each micro-project gets its own directory:

```text
AI_WORKFLOW_WORKSPACE_HOME/micro-projects/<slug>/
```

Micro-projects still require risk classification and evidence. If the work touches auth, billing, permissions, migrations, secrets, production data, security, external effects, or architectural decisions, route it to the full workflow.
