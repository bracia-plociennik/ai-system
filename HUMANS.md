# HUMANS.md

## Purpose

This is the human runbook for the `ai-system` branch.

AI System helps organize local client and project work without turning private files into public repo content.

## Core Habit

Use `dump/incoming/` as an inbox. Ask AI to classify files first, then approve exact moves.

## Useful Prompts

```text
Co teraz? Sprawdź status workspace, dump, aktywnych klientów, projektów, pamięć i checkpointy. Podaj jedną rekomendację i jedną alternatywę.
```

```text
Przejrzyj dump/incoming. Sklasyfikuj pliki, zaproponuj klienta/projekt/docelowe miejsce, ale niczego nie przenoś bez owner-approved.
```

```text
Zrób destylację pamięci klienta i zaproponuj zanonimizowane system-insights. Nie zapisuj danych identyfikujących klienta.
```
