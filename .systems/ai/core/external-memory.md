# External Memory

## Purpose

`external-memory/` stores suggestions for improving AI System itself.

Use it for:

- workflow improvements;
- template improvements;
- validation ideas;
- skill ideas;
- recurring tool issues.

Do not use it for client facts, project history, product-domain lessons, client-work lessons, frontend/backend/SEO/ads/smart-contract practices, skill rubrics, or owner competence lessons. Those belong in client/project memory or `system-insights/`.

Dream Reports may classify External Memory candidates for AI System product improvements, but Dreaming Mode must not write External Memory automatically.

## Cross-System Upgrade Handoffs

Substantive AI System or AI Workflow upgrades use `.systems/ai/core/cross-system-upgrade-handoff.md`.

When the owner decides `Cross-system impact: yes`, store one privacy-safe handoff under:

```text
<workspace>/external-memory/memory/<date>-<topic>-<counterpart>-handoff.md
```

Root-level entries already stored directly in `external-memory/` remain valid and are not migrated automatically.
