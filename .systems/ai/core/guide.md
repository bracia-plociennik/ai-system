# Guide

## Purpose

Guide mode helps the owner recover orientation.

Use it when the owner says:

- `co teraz`;
- `co dalej`;
- `zgubiłem się`;
- `jak zacząć`;
- `what should I do next`.

## Sources To Read

- `ai-system-workspace/core/status.md`;
- `ai-system-workspace/dump/dump-index.md`;
- client and project status files;
- memory and checkpoint routers;
- current open decisions.

## Response Shape

Return current status, blockers, one recommendation with impact, and one alternative with impact.
