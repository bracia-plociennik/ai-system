# System Insights

## Purpose

`system-insights/` stores anonymized lessons that improve the owner's competence, offer, process, and quality of work.

It is not the same as `external-memory/`.

## Must Be Anonymized

Before writing to `system-insights`, remove or generalize:

- client names;
- people names;
- domains;
- amounts;
- contract details;
- secrets;
- unique project identifiers;
- any details that could identify the client.

## Promotion Rule

Client and project memory can be raw. `system-insights` receives only processed output from the owner-approved distillation prompt.
