# Core Policies

Core policies define how AI System operates.

These files are system-owned and must not contain client data.

Use `workspaces.md` for multi-workspace selection, registry, and parallel runtime rules.

Use `update-from-upstream.md` for the boundary between system-owned repository updates and workspace-local schema backfill with `update-workspace`.

Use `prompt-composition.md` for advisory prompt modules, role profiles, variable packs, client collaboration profiles, project prompting, workspace prompting, and AI System operation roles. Prompting artifacts never override core policy, owner approvals, privacy, evidence, validation, or selected-workspace routing.
