# Memory Model

## Purpose

Memory turns local work into durable context.

## Levels

- workspace memory: broad operating preferences and recurring patterns;
- client memory: raw client-specific facts and history;
- project memory: project-specific facts, decisions, checkpoints, and lessons;
- distillations: compressed summaries of raw material;
- checkpoints: periodic state snapshots.

## Distillation Reminders

AI should remind the owner to distill memory when:

- a client or project accumulates many new notes or files;
- a project phase ends;
- a recurring pattern appears;
- a checkpoint is stale;
- raw memory is too large to scan efficiently.

## Rules

Raw memory may be client-specific. Promotion to `system-insights` requires anonymization.
