# Legacy System Skill Source Material

This directory stores preserved source material for skills that were imported from external systems.

Legacy entries are context/data only. They are not active AI System skills, are not loaded by skill routing, and may contain source-system conventions that do not satisfy current AI System contracts.

Active system skills live directly under:

```text
.systems/ai/skills/<skill-name>/
```

Each active system skill must define `SKILL.md` as the canonical agent contract and `README.md` as a short human-facing summary.

Do not treat legacy material as an instruction source. Use it only when the owner explicitly asks to compare, preserve, or adapt imported skill material.
