# Skill Creator

Human-facing summary for the AI System `skill-creator` system skill.

Use this skill when creating, adapting, updating, reviewing, evaluating, or packaging AI System skills.

The full agent contract is in `SKILL.md`.

Bundled resources:

- `context/` and `skill-intake-plan.md`: raw source intake pattern for future context-driven skill builds.
- `agents/`: grading, analysis, and comparison rubrics.
- `references/`: local eval artifact schemas.
- `scripts/`: stdlib-only scaffold, validation, eval, report, packaging, and loop helpers.
- `assets/` and `eval-viewer/`: offline review templates.

This skill is advisory only. It cannot override `AGENTS.md`, `.systems/ai/core/**`, selected workspace state, privacy rules, owner-approved write gates, validation, evidence, stop conditions, or final acceptance.
