# Owned Assets Template

Owned-asset workspaces store owner-controlled companies, brands, offers, products, and other commercial assets.

They use the same base directory structure as client workspaces, but they are not external clients. Keep private owner context in `humans/` or workspace memory unless it is explicitly part of the public or commercial asset.

Use `owned-asset-readme.template.md` for each `owned-assets/<asset>/README.md`.
