# Links Templates

Templates for workspace-local external source registries.

- `links-readme.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/links/README.md`
- `source.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/links/<source-slug>.md`

The source template is copied manually only when the owner approves creating a specific source record. `init-workspace` and `update-workspace` create only the neutral `links/README.md`.
