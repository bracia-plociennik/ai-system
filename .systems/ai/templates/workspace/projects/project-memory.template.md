# Project Memory Router

## Purpose

This file indexes project-specific memory inside the project-state namespace.

Detailed entries live in `project-state/<project>/memory/` as dated memory files.

## Memory Index

| Date | Topic | Type | Status | Route |
| --- | --- | --- | --- | --- |
| n/a | No project memory entries yet | n/a | n/a | n/a |

## Rules

- Keep this router short; store details in dated entries.
- Record decisions, constraints, risks, implementation notes, testing notes, and drift notes.
- Do not use memory as a substitute for current project files.
- Do not store this router in a managed project git repo unless the owner explicitly chooses colocated local-only state.
- Anonymize before promoting reusable lessons to `system-insights/`.
