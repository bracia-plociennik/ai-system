# Weekly Plans

This directory stores canonical Saturday plans for Monday-Friday work weeks.

- One plan per ISO week: `YYYY/YYYY-Www.md`.
- Sunday is intentionally outside the weekly plan.
- Use `.systems/ai/core/weekly-planning.md` for the contract.
- `weekly-plan.template.md` is a neutral template, not a real plan or TaskNote.
- TaskNotes are generated only after the weekly plan is ready and owner-approved.
