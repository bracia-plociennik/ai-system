# External Memory Template

External memory stores ideas for improving AI System itself.

Use it for workflow, template, validation, script, documentation, or system-skill improvement proposals.

Do not store client facts, project history, product-domain lessons, client-work lessons, frontend/backend/SEO/ads/smart-contract practices, skill rubrics, or owner work-quality lessons here. Use `system-insights/` for anonymized operating lessons.

Privacy-safe counterpart upgrade handoffs belong under `memory/` and follow `.systems/ai/core/cross-system-upgrade-handoff.md`.
