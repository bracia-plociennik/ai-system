# System Insights Workspace Templates

Templates used by `.systems/scripts/init-workspace` to create `AI_SYSTEM_WORKSPACE_HOME/system-insights/`.

Runtime files:

- `system-insights-readme.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/system-insights/README.md`
- `system-insights.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/system-insights/system-insights.md`
- `insights-readme.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/system-insights/insights/README.md`
- `system-insight.template.md` -> `AI_SYSTEM_WORKSPACE_HOME/system-insights/insights/YYYY-MM-DD-short-kebab-title.md`

Do not store raw client data, client names, secrets, repo-specific facts, project-specific details, or production identifiers in System Insights.
