# System Insights

`AI_SYSTEM_WORKSPACE_HOME/system-insights/` stores anonymized operational lessons that can improve future projects, client collaboration, delivery quality, offer design, and skill creation.

Detailed entries live in `insights/` and are indexed by `system-insights.md`.

System Insights are advisory. They do not override `AGENTS.md`, `.systems/ai/core/`, workspace status, memory, decisions, checkpoints, privacy rules, validation, stop conditions, owner approvals, or skills.

Use System Insights for:

- frontend, backend, smart contract, SEO, ads, product, process, quality, offer, client-work, and skills lessons;
- anonymized best practices from projects;
- skill candidates that need later promotion through the normal skill workflow.

Do not use System Insights for:

- raw client data;
- client names or personal data;
- secrets, credentials, wallet private keys, API keys, production credentials, `.env` content, or internal URLs;
- repo-specific facts or project-specific details;
- AI System product improvement proposals, which belong in `AI_SYSTEM_WORKSPACE_HOME/external-memory/`.

Persistent insight writes happen only through checkpoint/final-review routing or explicit owner-approved capture.
