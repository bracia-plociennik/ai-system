# Dreams Workspace Templates

Templates used by `.systems/scripts/init-workspace` and `.systems/scripts/update-workspace` to create `AI_SYSTEM_WORKSPACE_HOME/dreams/`.

Dream Reports are advisory-only and belong under `AI_SYSTEM_WORKSPACE_HOME/dreams/runs/**`.

`dreaming-scope.local.template.md` defines the machine-readable, narrow-only workspace source guard. Workspace bootstrap copies it only when the local scope does not already exist.
